# شیفت‌یار

برنامه‌ریز شیفت پرسنل درمانی با تقویم شمسی. یک صفحهٔ تک‌فایل HTML بدون وابستگی ساخت (build) سنگین.

## امکانات فعلی
- شیفت‌های M / A / N و ترکیبی‌های MA / AN / NM / MN؛ ساعت هر شیفت از **اجتماع بازه‌ها** محاسبه می‌شود (هم‌پوشانی ۳۰ دقیقه‌ای فقط یک‌بار شمرده می‌شود). شیفت سفارشی هم قابل تعریف است.
- پرسنل با نوع قرارداد (شرکتی، تبصره ۴، رسمی) و بخش‌های نامحدود با رنگ مخصوص.
- تقویم شمسی ماهانه، رنگ‌آمیزی شیفت با کشیدن ماوس، مرخصی (استحقاقی/بدون حقوق)، استعلاجی، استراحت، غیبت.
- موظفی ماهانه = (روزهای ماه − جمعه‌ها − تعطیلات رسمی) × ۷:۲۰
- تعطیلی از ۰۰:۰۰ تا ۲۴:۰۰ و ضریب ۱.۴ برای شرکتی و تبصره ۴ (شیفتِ عبورکننده از نیمه‌شب بین دو روز تقسیم می‌شود)
- اضافه‌کار/کسر کار، هشدار حداقل فاصلهٔ بین شیفت‌ها، گزارش بازه‌ای، خروجی CSV، پشتیبان JSON و گزارش تغییرات.

## ساختار
| فایل | کار |
|---|---|
| `core.js` | محاسبات خالص (بدون DOM): تقویم جلالی، شیفت‌ها، تعطیلات، موظفی، اضافه‌کار |
| `ui.js` | رابط کاربری و ذخیره‌سازی |
| `style.css` | ظاهر (تم روشن و تیره) |
| `shell.html` | قالب صفحه |
| `build.py` | ساخت `shiftyar.html` از فایل‌های بالا |
| `test.js` | تست‌های `core.js` |
| `gen-sample.js` | ساخت داده‌های نمونه در `sample/` |

## اجرا و تست
```bash
node test.js            # تست محاسبات
python3 build.py        # ساخت shiftyar.html
```
فایل `shiftyar.html` را می‌توان مستقیم در مرورگر باز کرد؛ در این حالت داده‌ها در `localStorage` همان مرورگر می‌مانند (حتماً پشتیبان بگیرید).

## ذخیره‌سازی
- داخل claude.ai (Artifact): در پایگاه‌دادهٔ `db` — سند `app/config`، سند `app/log` و یک سند برای هر ماه `assign/<سال>-<ماه>`.
- بیرون از آن: `localStorage`.

## فرض‌های محاسبه (قابل تغییر در تنظیمات)
- جمعه تعطیل رسمی است.
- مرخصی استحقاقی و استعلاجی در روز کاری ۷:۲۰ اعتبار می‌گیرند و در تعطیل اعتبار ندارند.
- تعطیلات قمری هر سال را باید دستی اضافه کرد.

## ایده‌های بعدی
- سطوح دسترسی (ادمین، مدیر بخش، پرسنل) و درخواست مرخصی/جابه‌جایی شیفت (نیازمند سرور)
- اطلاع‌رسانی با پیامک/ایمیل
- خروجی xlsx و pdf
- پیشنهاد خودکار برنامه بر اساس نیاز هر بخش
